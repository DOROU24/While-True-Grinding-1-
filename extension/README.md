# Impulse Blocker - Инструкция по установке

Это расширение для Chrome, которое помогает бороться с импульсивными покупками.

## 🚀 Как установить в Chrome

1.  Откройте браузер **Google Chrome**.
2.  В адресной строке введите: `chrome://extensions` и нажмите Enter.
3.  В правом верхнем углу включите переключатель **"Режим разработчика"** (Developer mode).
4.  Появится панель с кнопками. Нажмите **"Загрузить распакованное расширение"** (Load unpacked).
5.  В открывшемся окне выберите папку с проектом:
    `/home/logac/Pokupach`
6.  Нажмите **ОК** / **Выбрать**.

🎉 **Готово!** Значок расширения появится справа от адресной строки.

## 🛠 Обновление (после изменений в коде)

Если я (ваш ассистент) внес изменения в код (исправил баги, добавил фичи), вам нужно обновить расширение в браузере:

1.  Вернитесь на вкладку `chrome://extensions`.
2.  Найдите карточку **"Impulse Blocker"**.
3.  Нажмите кнопку **обновления** (значок круговой стрелки) в правом нижнем углу карточки.
4.  Обновите страницу магазина (F5), чтобы изменения вступили в силу.

## 📋 Возможности

*   **Стоп-лист**: Блокирует кнопки "Купить" для определенных категорий товаров.
*   **Умный бюджет**: Если стоимость товара превышает ваш остаток лимита на месяц — покупка блокируется.
*   **Таймер осознанности**: Вместо блокировок можно просто отложить покупку на 1 час (или 1 минуту для тестов).
